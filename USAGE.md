# 🌾 FarMora - Quick Start Guide

## Getting Started

1. **Sign Up / Login** - Create an account or login to access all features
2. **Select Language** - Click the globe icon (🌐) in the top bar to switch between 10 Indian languages

---

## Features

### 💬 AI Chat Assistant
Just type your farming questions in the chat box. FarMora understands queries about:
- Crop cultivation tips
- Pest management
- Soil health
- Irrigation advice

### 🔬 Disease Detection
1. Click the **📎 attachment** icon
2. Upload a photo of your affected crop
3. Get instant AI-powered diagnosis with treatment recommendations

### 📅 Task Planner
- Ask "Plan tasks for my tomato crop" 
- Get personalized farming schedules
- View tasks in the **Timeline** section (sidebar)

### 📊 Dashboard
Access your farming dashboard from the sidebar to view:
- Crop overview
- Task progress
- Weather updates

### 📰 Market Intelligence
Click **Market** in the sidebar to view:
- Latest agricultural news
- Crop price trends

## Quick Tips

| Action | How |
|--------|-----|
| New chat | Click **+ New Chat** in sidebar |
| Switch language | Globe icon → Select language |
| Upload image | 📎 icon in chat input |
| View history | Sidebar → Chat history |
| Logout | User icon → Logout |
